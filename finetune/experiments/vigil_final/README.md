# VIGIL Final Experiments

This package contains the post participant-CV research work for VIGIL:

- strict nested participant-disjoint cross-validation;
- development-only Stage 2 operating-point analysis;
- real support-driven prototype and gradient onboarding experiments;
- component cost, memory, and Qwen-call accounting;
- shared-Qwen hidden-state diagnostics;
- balanced-versus-full-data and long-speech stress-test tooling;
- locked future blind-test protocol support.

Generated runs, logs, private support lists, embeddings, predictions, checkpoints, and model bundles are ignored by Git. Public reports must contain only participant aliases such as `P001`.
